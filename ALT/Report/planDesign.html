Plan and design.

Design Objective 1

- To detect a newly started fire as quickly as possible and have the system automaticly take the necasary ssteps to extinguish it.
Why did I choose this goal?
- The ability to detect fires early on is something I found on existing systems in my research such as the DRYAD system.
How will I achieve this?
- I will use a flame detector sensor which when it detects a fire it will trigger a flashing red LED and turn on a water pump which will run until a fire is no longer detected.

Design Objective 2

- Have a visible indicator when something is wrong such as soil moisture being too low.
Why did I choose this goal?
- Following my investigation on existing systems, I saw visible indicators in nearly all of them, so I decided to add them to mind.
How will I achieve this?
- I will achieve this by using a an if statement linked to my sensors e.g if soil moisture > 50 LED's start flashing.

Design Objective 3

- Have a false alarm detector
Why did I choose this goal?
- Following my investigation on existing systems, I saw most existing solutions had a way of detecting false alarms.
How will I achieve this?
- I will achieve this by either comparing sensor outputs e.g if soil moisture is high but flame sensor is retuning a zero meaning that a fire is sensed or creating a way for the system to not return outliers such as temps above 45 degrees.

Technologies Used

-VS Code: This is a code editor used for programming in many languages including Python. I used it to write and manage the code for my project and to run my Python programs. I chose VS Code because it has useful features like extensions and debugging tools
-PC
-Microbit: A small programmable microcontroller. I used the Micro:bit to read the values from the sensors such as the moisture sensor, flame sensor, and air humidity sensor and send the data to my computer.
-Thermometer: This is a temperature sensor used to measure the surrounding air temperature. I used it in my project to help calculate the fire risk, as higher temperatures increase the chance of fires starting.
-Flame Sensor: This is a sensor that detects the presence of fire or flame. I used it to determine if a fire had started in the environment so that my system could react accordingly.
-Moisture Sensor: This is a sensor used to measure the moisture level in soil. I used it to determine how dry the ground was, as drier soil increases the risk of forest fires.
-Air Humidity Sensor: This is a sensor that measures the humidity of the air. I used it because low air humidity increases the likelihood of fires spreading in a forest environment.
-Water Pump
-Green House: This is the small plastic environment where I placed my sensors.
LED: This is a light emitting diode used as a visual indicator. I used the LED to show when certain conditions were triggered.
