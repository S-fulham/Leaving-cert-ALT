Evaluation.

Requirments Requirments Met?
BR 1: Embedded system design Yes

Inputs
-Fire Sensor digital, returns one if no fire detected and 0 if fire detected
-Moisture Sensor analogue, returns soil moisure as a percentage.

Outputs
-LED digital, LED turns on if soil moisture low
BR 2: Data Collection Yes

- My embedded collects and stores temperature, soil moisture and air humidity all of which are used live in my model. (The system also collects and stores flame detection data although it is not used in the model.)
BR 3: Process simulation Yes

I simulated a drought by taking out the soil moisture sensors and drying it, this system responded by turning on a red LED to let me soil moisture was low and the water pump automaticly activated.

Advanced Requirments

Requirments Requirments Met?
AR 1: Disaster risk modelling Yes - I chose to model wildfire and modeled the chance of a fire starting/spreading based on data gathered from my Microbit and data from online data sets (temperature, moisture level, distance between trees, air humidity)
AR 2: What-if simulations: Yes - My model looks at a 2 variables moisture levels (drought conditions) and temperature levels.
AR 3: Adaptive system: Yes - My system includes multiple responses depending on the data recieved by the sensors including water pump turning on if fire is detected and not turning off until the fire is no longer detected, water pump turning on for three seconds if moisture level is low, LED turning on if temperature is high.

Improvements That Could Be Made

The first improvements I would make is using more acurate sensors, justification this would make the system much more reliable and also improve the model.
The second improvements I would make is using taking wind/wind speed into account, justification based on my research I found the wind strenght and speed has a huge affect on how fast and far a fire spreads taking wind into account in my system would greatly improve how useful it is.
he final improvements I would make is adding a noise alarm justification currently the model only uses LED's as an alram system which might not always be noticed, a noise alarm would be much easier to notice therefore making the system alot safer.
