For the sensor code: For the Sensor code, the biggest challenge that I experienced was setting up the connection between the sensors and the pc and getting the connection to work reliably. Early in testing I had an issue getting an acurate reading from the sensors and I could not figure out what the problem was. This lead me to print the values I was reading every second me from this I noticed every few readings the values would be wildly off from this I realised that calling the values from the sensors too frequently would break them. From this I resolved the problem by only taking readings every 10 seconds. 


import serial
from datetime import datetime
import time


ser = serial.Serial("COM14", 115200)
time.sleep(10) #corrected time issue


with open("log.csv", "w") as file:
    file.write("Timestamp, soilMoisture, Temperature,  Flame, airHumidity\n")
while True:
    line = ser.readline().decode().strip()
    timestamp = datetime.now().strftime("%H:%M:%S")


    print("Logging", timestamp, line)


    with open("log.csv", "a") as file:
        file.write(f"{timestamp},{line}\n")
