For the model code: This model is a forest fire simulation. It uses a 20 by 20 grid to represent a forest, where each tree starts as a normal tree emoji. At the beginning, the tree in the middle is set on fire, and the program then checks whether the fire spreads to nearby trees. The model also takes in live sensor readings from the Micro:bit through serial communication. These readings are:

  • Temperature
  • Air humidity
  • Soil moisture
These values are used to work out how likely it is that a tree will catch fire. The algorithm works in a loop. First, it reads the latest sensor values. Then it goes through every tree in the forest one by one. If a tree is already burning, it becomes burnt in the next step. If a tree is not burning, the program checks its eight neighbouring trees around it. If at least one neighbour is on fire, the program calculates a fire chance. The fire chance is a number between 0 and 1. A value closer to 1 means the fire is more likely to spread.

This is calculated using the sensor data:
-Higher temperature increases the fire risk
-Lower air humidity increases the fire risk
-Lower soil moisture increases the fire risk

The formula gives each factor a weighting: Temperature contributes 40%
Air humidity contributes 30%
Soil moisture contributes 30%

So in simple terms, the model says:
hotter + drier air + drier soil = higher fire risk

After that, the code generates a random number between 0 and 1 and compares it to the calculated fire risk. If the random result matches the condition, the tree catches fire. This adds some realism, because in real life fire spread is not perfectly predictable every time. The forest is then updated and printed again so you can watch the fire spread across the grid step by step. The simulation continues until there are no burning trees left.

# imports all the libairy I need
import random
import time
import copy
import serial


#creats the 2D grid
WIDTH = 20
HEIGHT = 20
forest = [["🌲" for i in range (HEIGHT)] for i in range(WIDTH)]
#variables
ser = serial.Serial("COM14", 115200)
time.sleep(3)
Flame = 0
Temperature = 0 
soilMoisture = 0
airHumidity = 0
moistureLevel = 0

# gets values from the sensors they're returned in list so I have to strip them to get the values to run the model
def getValues():
    line = ser.readline().decode().strip()
    parts = line.split(",")
    soilMoisture = int(parts[0])
    Temperature = int(parts[1])
    airHumidity = int(parts[3])
    return  Temperature, airHumidity, soilMoisture


#prints the forest
def printForest(forest):
    for row in forest:
        print(" ".join(row))
    print()

#this function gets the neighbouring trees
def getNeighbours(x,y):
    directions = [(-1,1), (1,0), (1,1),
                (-1,0),          (0,1),
                (-1,-1), (0,-1), (1,-1)]
    neighbours = []
    for dx, dy in directions:
        nx, ny = x + dx, y + dy
        #makes sure the trees arent out of bounds
        if 0 <= nx and nx < HEIGHT and 0 <= ny and ny < WIDTH:
            neighbours.append((nx, ny))
    return neighbours


#makes the center of the 2D list tree on fire 
forest [HEIGHT//2][WIDTH//2] = "🔥"

while True:
    Flame, Temperature, soilMoisture, airHumidity = getValues()
    newForest = copy.deepcopy(forest)
    for x in range (HEIGHT):
        for y in range (WIDTH):
            #sets burning trees to burnt
            if forest[x][y] == "🔥":
                newForest[x][y] = "."
            #if the tree isnt on fire the neighbouring trees are checked to see if they are burning, 
            if they are the their is a chance for this one to catch on fire 
            elif forest [x][y] == "🌲":
                neighbours = getNeighbours(x,y)
                #calculates the fire chance
                if any (forest[x][y] == "🔥" for x,y  in neighbours):
                    fireChance=random.random()
                    realFire = 0
                    realFire += (Temperature / 40) * 0.4 
                    realFire += (1 - airHumidity / 100) * 0.3  
                    realFire += (1 - soilMoisture / 100) * 0.3  
                    realFire = max(0, min(realFire, 1))   
                    if fireChance < realFire:
                        newForest[x][y] = "🔥" 
    if not any("🔥" in row for row in forest):
        printForest(forest)
        break
    #prints the updated forest and sets the new forest to the original one
    printForest(forest)
    forest=newForest
    print ("This is the moisture level ", moistureLevel)
    print ("This is the temperature ",Temperature)
    print ("This is the air humidity level ",airHumidity)
    print ("This is the the chance of a fire starting level ",realFire)

    #wait one second before printing again
    time.sleep(1)

A Problem I faced

The biggest problem I faced throughout the entire project was getting my model to read live values from the Micro:bit sensors and then use those values correctly in the simulation. At first, it was difficult to connect the serial data from the Micro:bit to the Python program in a way that was reliable. I had to make sure the sensor values were being sent in the right order, read properly by Python, and converted into percentages before the model could use them. I solved this by, instead of trying to get the model to read the data from the sensors themselves, I had the model read the data collected in the CSV file. Once this was solved the model was able to use the real sensor readings such (temperature, air humidity, and soil moisture) to control how the fire spread in the model.
